I'm Abdulla Al Saba, a MERN Stack Developer who enjoys turning ideas into clean, responsive, and scalable web applications. What pulled me into programming wasn't a single moment — it was the slow realization that every website I used was just logic and structure someone had carefully put together, and I wanted to learn how to build that myself.

Since then, I've been building with MongoDB, Express.js, React, Node.js, Next.js, and Tailwind CSS, working across the full stack — from designing APIs and data models to shaping the interfaces people actually interact with. Alongside project work, I practice algorithmic problem-solving on LeetCode to keep my core programming fundamentals sharp, because I've found that good architecture and clean logic usually come from the same place.

I care about writing code that's easy to reason about, not just code that works. Outside of building, I spend time studying design decisions in products I admire and looking for small ways to improve how I think through problems. My goal is simple: keep building things that are useful, well-made, and worth being proud of.
