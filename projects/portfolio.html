Description

My personal portfolio website showcasing my skills, projects, and professional identity with a modern responsive UI. Built from scratch with vanilla HTML, CSS, and JavaScript — featuring a cinematic hero experience, smooth section transitions, and a clean content panel. Deployed with a custom domain and SEO optimization.

Key Features

  • Custom cursor and interactive hero section built with vanilla JavaScript
  • Smooth panel transitions between About, Skills, Education, Projects, and Contact
  • Fully responsive layout with no external UI framework
  • Custom domain deployment with SEO and Open Graph optimization
  • Working contact form with client-side validation
  • Accessible navigation with a mobile-friendly menu

Challenges Faced

Balancing motion and visual polish with readability and responsiveness across devices, while keeping the UI minimal and consistent, was the biggest challenge — especially building the cursor and transition effects in plain JavaScript without a framework to lean on.

Future Improvements

Add a full resume view, enhance accessibility (keyboard flow and ARIA), and include more case-study style breakdowns for projects.
